# Project Roadmap

This repository tracks the evolution of the **Secure Smart Parking & Access Control System** through versioned milestones.

## V1 - Ultrasonic Proximity-Based Automatic Gate

Status: WORKING

Scope:
- HC-SR04 ultrasonic distance sensing
- 16x2 LCD status display
- Piezo buzzer alerts
- SG90 servo gate control

## V2 - RFID-Based Secure Access

Status: PLANNED

Planned:
- RC522 RFID reader
- Authorized and unauthorized RFID cards
- Access granted/denied based on card authentication
- Gate control based on authentication

## V3 - Smart Parking Slot Management

Status: PLANNED

Planned:r
- Multiple parking-space sensors
- Occupancy detection
- Available-space count
- Gate access based on parking availability

## V4 - IoT Monitoring

Status: PLANNED

Planned:
- ESP32
- Wi-Fi
- Remote monitoring
- Event logging
- Web dashboard

## V5 - Optional Computer Vision

Status: PLANNED

Planned:
- Camera
- License plate recognition
- Vehicle identification
- Integration with authorization system
